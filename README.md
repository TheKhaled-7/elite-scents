# 🌟 Elite Scents

A modern luxury perfume store built with **HTML, CSS, and JavaScript** featuring an elegant UI, shopping cart functionality, and WhatsApp checkout.

---

## 📸 Preview

Elite Scents is a responsive landing page for a premium fragrance brand with a luxury-inspired interface.

### Features

- ✨ Modern luxury UI
- 📱 Fully responsive design
- 🛒 Shopping cart
- 💾 Cart saved using Local Storage
- 📦 Dynamic cart updates
- 💰 Automatic total price calculation
- 📲 WhatsApp checkout integration
- 🎨 Smooth animations and glassmorphism effects

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Local Storage API
- WhatsApp API

---

## 🛒 Shopping Cart

The shopping cart supports:

- Add products
- Remove products
- Save cart after refresh
- Calculate total price
- Checkout directly through WhatsApp

---

## 📲 WhatsApp Checkout

When the customer clicks **Checkout**, the website automatically creates an order message containing:

- Product names
- Individual prices
- Total price

Then opens WhatsApp with the order ready to send.
